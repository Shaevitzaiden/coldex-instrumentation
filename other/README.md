# Reference / not-yet-integrated work

Content under `other/` is useful project work that is **not automatically part of the main `pneumatic_valve_panel` runtime package**.

At present the most important item is `vacuum_instrumentation_bundle_v2/`, which contains the GRAPHIX driver, GP475/PDR-D-1 conversions, Feather Adalogger firmware, wiring notes, and BOM snapshots. Promote code from here into `src/pneumatic_valve_panel/` only when it is ready to follow the main DeviceManager/StreamHub integration contract.
